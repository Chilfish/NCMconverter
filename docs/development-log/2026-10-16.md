## 复用层：`internal/app` 暴露 `Scan` 与 `OnFile`（提交 ①，`refactor:`，✅ 已完成）

**背景**：`app.Run` 只把每文件结果写进 `slog`，桌面拿不到结构化进度；还需要一个「开跑前展示工作量」的入口。

**实现**：新增 `internal/app/report.go`（`Outcome` 常量 + `FileResult`）；`Options` 增加 `OnFile func(FileResult)`（**在既有互斥锁内**调用，天然串行）；`collect` → 导出 `Scan`（同一实现、同一行为，只改名 + 补文档注释）；`convert` 改为返回 `(FileResult, error)`，在算出 `outputPath` 后填 `Dest`。既有 `slog` 调用与 `Run` 签名不变——[ADR-010](../planning/architecture.md)、[features/cli](../features/cli/cli-and-orchestration.md)。

**验证**：`report_test.go` 锁定试运行/成功/跳过/失败四种回调与「无回调时行为不变」；`app_test.go` 两处调用点改名。行为不变，CLI 输出、参数与退出码不动。

**文档**：[features/cli/cli-and-orchestration.md](../features/cli/cli-and-orchestration.md)（`Scan`/`OnFile`）、CHANGELOG。

## 界面改用 MyGo 原生 UI（✅ 已完成）

**背景**：当日早些时候的桌面用 web 前端（HTML/TypeScript + Vite + `mygo generate` 生成的客户端）；实测下来界面不像原生应用、UX 也差。当日改为 MyGo 的 `package ui` 原生 UI（Go 直接声明、GPU 绘制），[ADR-011](../planning/architecture.md) 取代了原 [DD-3](../requirements/desktop/05-review/design-decisions.md)。

**实现**：删除 `desktop/`（`index.html`、`src/main.ts`、`src/style.css`、`src/mygo.ts`）与仓库根的 `package.json`、`tsconfig.json`、`vite.config.ts`、`bun.lock`、`mygo.config.ts`，以及旧的绑定服务 `internal/desktop/service.go`；新增纯数据配置 `mygo.json`；`go.mod` 加入 tool 指令 `tool github.com/egoist/mygo/cmd/mygo`，MyGo CLI 改为 `go tool mygo`，不再需要 Node/bun；`Makefile` 新增 `dev` / `desktop`（`go tool mygo dev` / `go tool mygo build`）并删除 `generate` / `typecheck`；CI 与发布链路去掉 bun（桌面 job 只跑 `make desktop`，发布跑 `go tool mygo build`）。

窗口（`internal/desktop/app.go`）用 `mygo.NewWindow`：隐藏系统标题栏 + `VibrancySidebar` 材质 + 自绘内嵌标题栏（`TitleBarHiddenInset` + `Context.TitleBar` + `DragWindow`），侧栏分 转换队列 / 选项 / 日志 三段。视图（`internal/desktop/view.go`）每帧重绘：队列用 `scanBySource` 把每个容器归属到它的来源，逐来源显示阶段（待处理 / 转换中 / 已转换 / 失败 / 无 .ncm / 路径不可用）与标记（环 / 旋转 / 对勾 / 感叹），另有运行汇总卡片与标题栏的运行状态药丸。

**验证**：`internal/desktop/runner_test.go` 继续用 `internal/ncmtest` 夹具、无窗口驱动转换内核；新增 `view_test.go`，用 `ui.NewTester` 在内存里渲染视图并断言（点击、`HasText`/`Texts`），**无需窗口**——推翻仓库早年「桌面 UI 不做自动化测试」的立场。门禁 `make fmt-check vet test-race build` 与 `make desktop` 全绿。Linux 桌面模式只需 GTK 3。

**文档**：[ADR-011](../planning/architecture.md)、[features/desktop/desktop-app.md](../features/desktop/desktop-app.md)、[UI 设计](../requirements/desktop/02-design/ui-design.md)、[engineering/testing.md](../engineering/testing.md)、CHANGELOG。
